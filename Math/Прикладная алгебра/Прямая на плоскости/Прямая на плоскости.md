# Прямая на плоскости

## 1. Векторное уравнение
$M_0 \in l$, $\vec a \neq \vec 0$, $l \parallel \vec a$.

![[Векторное уравнение прямой.png|300]]

$\overrightarrow{M_0M} = \vec r - \vec r_0$

**Направляющий вектор прямой** $\vec s$ — любой ненулевой вектор, лежащий на прямой или коллинеарный ей. $\vec s \parallel \overrightarrow{M_0M}$, значит $\exists t \in \mathbb R:\ \vec r - \vec r_0 = \vec s\,t$:
$$\boxed{\vec r = \vec r_0 + \vec s\,t}$$
Если $O \in l$, то $\vec r_0 = \vec 0$ и $\vec r = \vec s\,t$.

**Нормальный вектор прямой** $\vec N$ — любой ненулевой вектор, перпендикулярный прямой.

![[Нормальный вектор прямой.png|260]]

$$\vec N \cdot \vec r + C = 0, \qquad C = -\vec N \cdot \vec r_0$$
Если $O \in l$: $\vec N \cdot \vec r = 0$.

## 2. Общее уравнение прямой
В декартовой системе координат любую прямую на плоскости можно задать уравнением первой степени:
$$Ax + By + C = 0, \qquad A, B, C \in \mathbb R,\quad A^2 + B^2 > 0,\quad \vec N = \{A;\ B\}$$

Через точку $M_0(x_0;y_0)$: $\ Ax + By + \underbrace{(-Ax_0 - By_0)}_{C} = 0$

**Частные случаи:**

| Условие | Уравнение | Прямая |
|---|---|---|
| $C = 0$ | $Ax + By = 0$ | проходит через начало координат |
| $B = 0,\ C \neq 0$ | $x = a = -\dfrac CA$ | параллельна $Oy$ |
| $A = 0,\ C \neq 0$ | $y = b = -\dfrac CB$ | параллельна $Ox$ |

![[Прямая через начало координат.png|230]] ![[Прямая параллельная Oy.png|230]] ![[Прямая параллельная Ox.png|230]]

## 3. Уравнение с угловым коэффициентом
При $B \neq 0$: $\ By = -Ax - C \Rightarrow y = -\dfrac AB x - \dfrac CB$. Обозначим $k = -\dfrac AB$, $b = -\dfrac CB$:
$$y = kx + b, \qquad k = \operatorname{tg}\alpha$$

![[Угловой коэффициент.png|300]]

1. Если $b = \mathrm{const}$, а $\alpha$ меняется, прямая $l$ вращается вокруг точки $B(0;b)$.
2. Если $\alpha = \mathrm{const}$, а $b$ меняется ($-\infty < b < \infty$), получаем семейство параллельных прямых.

**Через точку $M_0(x_0;y_0)$ с угловым коэффициентом $k$:**
$$\boxed{y - y_0 = k(x - x_0)}$$
$$y = kx + (y_0 - kx_0) = kx + b$$

## 4.1. Параметрическое уравнение
![[Параметрическое уравнение прямой.png|250]]

$\vec r = x\vec i + y\vec j$, $\ \vec r_0 = x_0\vec i + y_0\vec j$, $\ \vec s = \{m;\ n\}$. Подставляем в $\vec r - \vec r_0 = \vec s\,t$:
$$x\vec i + y\vec j - x_0\vec i - y_0\vec j = mt\,\vec i + nt\,\vec j$$
$$\begin{cases} x = x_0 + mt \\ y = y_0 + nt \end{cases}$$

## 4.2. Каноническое уравнение
Выражаем $t$ из обоих уравнений и приравниваем:
$$\frac{x - x_0}{m} = \frac{y - y_0}{n}$$
1. $m \neq 0,\ n \neq 0$ — общий случай
2. $m = 0$: $\vec s = \{0;n\}$, $x = x_0$, $y = y_0 + nt$, то есть $l \parallel Oy$
3. $n = 0\ (m \neq 0)$: $\vec s = \{m;0\}$, $x = x_0 + mt$, $y = y_0$, то есть $l \parallel Ox$

## 5. Уравнение прямой через две точки
$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1}$$
(здесь $m = x_2 - x_1$, $n = y_2 - y_1$)

## 6. Уравнение прямой в отрезках
![[Уравнение в отрезках.png|300]]

Подставим $A(a;0)$ и $B(0;b)$ в уравнение через две точки:
$$\frac{x - a}{0 - a} = \frac{y - 0}{b - 0} \;\Rightarrow\; -\frac xa + 1 = \frac yb \;\Rightarrow\; \boxed{\frac xa + \frac yb = 1}$$
1. Если $a = \mathrm{const}$, а $b$ меняется, прямая вращается вокруг $A$.
2. Если $b = \mathrm{const}$, а $a$ меняется, прямая вращается вокруг $B$.

## 7. Нормальное уравнение прямой
![[Нормальное уравнение прямой.png|300]]

$P_0$ — основание перпендикуляра из начала координат, $|OP_0| = p$, $\ \vec n^0 = \{\cos\alpha;\ \cos\beta\}$ — единичная нормаль.
$$M(x;y) \in l \iff \overrightarrow{P_0M} \perp \vec n^0 \iff \vec n^0 \cdot \overrightarrow{P_0M} = 0$$
$$\cos\alpha\,(x - x_0) + \cos\beta\,(y - y_0) = 0$$
$$\boxed{x\cos\alpha + y\cos\beta - p = 0}$$

**Переход от общего уравнения:** умножить $Ax + By + C = 0$ на нормирующий множитель
$$\mu = \pm\frac{1}{\sqrt{A^2 + B^2}}$$
Знак $\mu$ выбирают противоположным знаку $C$.

## 8. Пучок прямых
![[Пучок прямых.png|260]]

Все прямые через точку $M_0(x_0;y_0)$: $\ y - y_0 = k(x - x_0)$.

## 9. Взаимное расположение прямых на плоскости
$$l_1:\ A_1x + B_1y + C_1 = 0, \qquad l_2:\ A_2x + B_2y + C_2 = 0$$

> [!note] Дополнение (в конспекте тема обрывается)
> - пересекаются: $\dfrac{A_1}{A_2} \neq \dfrac{B_1}{B_2}$
> - параллельны: $\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} \neq \dfrac{C_1}{C_2}$
> - совпадают: $\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} = \dfrac{C_1}{C_2}$
> - перпендикулярны: $A_1A_2 + B_1B_2 = 0$ (то есть $\vec N_1 \cdot \vec N_2 = 0$)

## Приёмы из домашнего задания
- Из $Ax + By + C = 0$: нормаль $\vec n = (A; B)$, направляющий вектор $\vec s = (-B; A)$ (или $(B; -A)$). Проверка: $\vec n\cdot\vec s = 0$.
- Из канонического в общее — «крест-накрест»: $\dfrac{x - 1}{2} = \dfrac{y - 3}{-5} \Rightarrow -5(x - 1) = 2(y - 3) \Rightarrow 5x + 2y - 11 = 0$. Аккуратно раскрывай скобки со знаком.
- Направляющие $(3; 1)$ и $(6; 2)$ коллинеарны, значит прямые параллельны или совпадают — проверь, лежит ли точка одной прямой на другой.
- Точку на прямой по параметру находят из $\vec r = \vec r_0 + t\vec s$.
- Через две точки $A$ и $B$: направляющий вектор $\vec s = \overrightarrow{AB}$.

> [!warning] Типичные ошибки
> - $4x + 8 = 0 \Rightarrow x = -2$ — **вертикальная** прямая.
> - $2y - 6 = 0 \Rightarrow y = 3$ — **горизонтальная** прямая.
> - $x - 5y = 0$ ($C = 0$) проходит через начало координат.
> - $3x + 2y - 4 = 0 \Rightarrow \dfrac{x}{4/3} + \dfrac{y}{2} = 1$ (переносим $C$ направо и делим на него).
