# Векторы. Линейные операции и базис

**Направленный отрезок** — отрезок, у которого указано, какая точка начальная, а какая конечная: $(A;B)$, $\overrightarrow{AB}$, $\vec a$.
- $\overrightarrow{BA}$ — вектор, противоположный $\overrightarrow{AB}$
- $|\overrightarrow{AB}|$ — длина вектора
- $|\vec e| = 1$ — **единичный вектор (орт)**, сонаправленный с $\vec a$: $\vec a_0 = \dfrac{\vec a}{|\vec a|}$

**Коллинеарные** векторы ($\vec a \parallel \vec b$) лежат на одной прямой или на параллельных прямых.
**Компланарные** векторы лежат в одной плоскости или в параллельных плоскостях.
Сонаправленные: $\vec a \uparrow\uparrow \vec b$. Противоположно направленные: $\vec a \uparrow\downarrow \vec b$.

**Равные векторы:** $\vec a = \vec b$, если 1) $\vec a \uparrow\uparrow \vec b$ и 2) $|\vec a| = |\vec b|$.

![[Равные векторы.png|350]]

**Свободный вектор** — множество всех направленных отрезков, равных данному.
1. Каждому геометрическому вектору соответствует один свободный вектор.
2. Каждому свободному вектору соответствует множество равных между собой геометрических векторов.

## Линейные операции
**Сложение** — правило треугольника и правило параллелограмма:
$$\vec a + \vec b = \overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}, \qquad \vec a - \vec b = \vec a + (-\vec b)$$

![[Сложение векторов.png|400]]

**Умножение на число** $\alpha \in \mathbb R$: $\vec b = \alpha\vec a$, где
1. $|\vec b| = |\alpha|\,|\vec a|$
2. $\vec b \uparrow\uparrow \vec a$ при $\alpha > 0$, $\vec b \uparrow\downarrow \vec a$ при $\alpha < 0$

### Аксиомы линейного пространства
$\forall \vec a, \vec b, \vec c$, $\forall \alpha, \beta \in \mathbb R$:
1. $\vec a + \vec b = \vec b + \vec a$
2. $(\vec a + \vec b) + \vec c = \vec a + (\vec b + \vec c)$
3. $\vec a + \vec 0 = \vec a$
4. $\forall \vec a\ \exists(-\vec a):\ \vec a + (-\vec a) = \vec 0$
5. $(\alpha\beta)\vec a = \alpha(\beta\vec a)$
6. $\alpha(\vec a + \vec b) = \alpha\vec a + \alpha\vec b$
7. $(\alpha + \beta)\vec a = \alpha\vec a + \beta\vec a$
8. $1 \cdot \vec a = \vec a$

Множество всех свободных векторов пространства с введёнными операциями сложения и умножения на число называется **линейным (векторным) пространством**. Сложение — внутренняя операция, умножение на число — внешняя.

## Линейная зависимость
**Линейная комбинация:** $\vec b = \alpha_1\vec a_1 + \alpha_2\vec a_2 + \dots = \sum_i \alpha_i\vec a_i$

Система векторов **линейно независима**, если из $\sum_i \alpha_i\vec a_i = \vec 0$ следует, что все $\alpha_i = 0$. Если хотя бы одно $\alpha_i \neq 0$, система **линейно зависима**.

Свойства:
1. Если в системе есть нулевой вектор, она ЛЗ.
2. Система ЛЗ $\iff$ хотя бы один вектор можно выразить линейной комбинацией остальных.

Геометрический смысл:
1. Система из 1 вектора ЛЗ $\iff$ он нулевой.
2. Система из 2 векторов ЛЗ $\iff$ они коллинеарны ($\exists!\,\lambda:\ \vec a = \lambda\vec b$).
3. Система из 3 векторов ЛЗ $\iff$ они компланарны.

Если $\vec p, \vec q, \vec r$ некомпланарны, то любой $\vec a \in L_3$ единственным образом раскладывается по ним:
$$\vec a = \alpha\vec p + \beta\vec q + \gamma\vec r, \qquad \alpha, \beta, \gamma \in \mathbb R$$

## Базис
**Базис** — любая упорядоченная тройка линейно независимых векторов пространства.
1. На прямой — любой ненулевой вектор этой прямой.
2. На плоскости — пара неколлинеарных векторов $\{\vec e_1, \vec e_2\}$.
3. В пространстве — тройка некомпланарных векторов $\{\vec e_1, \vec e_2, \vec e_3\}$.

**Стандартный (ортонормированный) базис:**
$$\vec e_1 = \{1;0;0\},\ \vec e_2 = \{0;1;0\},\ \vec e_3 = \{0;0;1\}, \qquad |\vec e_i| = 1,\ \vec e_i \perp \vec e_j$$

- Два вектора равны $\iff$ равны их соответствующие координаты.
- Какая линейная зависимость между векторами, такая же и между их координатами.
- Координаты вектора: $\overrightarrow{AB} = B - A$ (из конца вычесть начало).

## Деление отрезка в отношении $\lambda$
Точка $M(x,y,z)$ делит отрезок $M_1M_2$ в отношении $\lambda$:
$$x - x_1 = \lambda(x_2 - x),\quad y - y_1 = \lambda(y_2 - y),\quad z - z_1 = \lambda(z_2 - z)$$
$$x = \frac{x_1 + \lambda x_2}{1 + \lambda}$$ (аналогично для $y$ и $z$)
