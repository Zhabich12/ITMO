# Комплексные числа

## Поле
Пусть на множестве $X$ заданы две операции, которые любым $x_1, x_2 \in X$ однозначно ставят в соответствие элемент $X$: $(x_1,x_2) \to x_1 \circ x_2$ и $(x_1,x_2) \to x_1 * x_2$.

Множество $X$ называется **полем**, если операции сложения и умножения:
1. коммутативны;
2. ассоциативны;
3. имеют нейтральные элементы: $0$ для сложения, $1$ для умножения;
4. $0 \neq 1$;
5. $\forall x\ \exists(-x):\ x + (-x) = 0$;
6. $\forall x \neq 0\ \exists x^{-1}:\ x \cdot x^{-1} = 1$;
7. связаны законом дистрибутивности.

$$\mathbb N \subset \mathbb Z \subset \mathbb Q \subset \mathbb R \subset \mathbb C$$

## Определение
Элементы $\mathbb C$ — пары действительных чисел $z = (x, y)$, $x, y \in \mathbb R$:
1. $z_1 + z_2 = (x_1 + x_2;\ y_1 + y_2)$
2. $z_1 \cdot z_2 = (x_1x_2 - y_1y_2;\ x_1y_2 + x_2y_1)$

**Мнимая единица** $i = (0;1)$:
$$i^2 = (0;1)(0;1) = (0\cdot0 - 1\cdot1;\ 0\cdot1 + 1\cdot0) = (-1;0) = -1$$

Отображение $x \to (x, 0)$ вкладывает $\mathbb R$ в $\mathbb C$. Тогда
$$z = (x,y) = (x,0) + (y,0)(0,1) \;\Rightarrow\; \boxed{z = x + yi} \text{ — алгебраическая форма}$$
$x = \operatorname{Re}z$, $y = \operatorname{Im}z$ (оба **действительные**, без $i$).

## Модуль и сопряжённое
$$|z| = \sqrt{x^2 + y^2}, \qquad |z| = 0 \iff z = 0$$
$\bar z = x - yi$ — сопряжённое число (меняется знак только у мнимой части).
$$z + \bar z = 2\operatorname{Re}z, \qquad z \cdot \bar z = |z|^2$$

## Операции в алгебраической форме
$$z_1 \pm z_2 = (x_1 \pm x_2) + (y_1 \pm y_2)i$$
$$z_1z_2 = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)$$
**Деление** — домножить числитель и знаменатель на сопряжённое к знаменателю:
$$\frac{z_1}{z_2} = \frac{z_1\bar z_2}{z_2\bar z_2} = \frac{(x_1x_2 + y_1y_2) + i(x_2y_1 - x_1y_2)}{x_2^2 + y_2^2}$$

## Геометрическая интерпретация
$z = x + iy$ — точка $(x, y)$ или вектор $\overrightarrow{OZ}$. Сумма — по правилу параллелограмма.

![[Комплексная плоскость.png|350]]

**Расстояние** между точками $z$ и $z_0$:
$$|z - z_0| = \sqrt{(x - x_0)^2 + (y - y_0)^2}$$

![[Расстояние между комплексными числами.png|400]]

Множества на плоскости:
- $|z - z_0| = R$ — окружность
- $|z - z_0| \le R$ — круг, $|z - z_0| < R$ — открытый круг
- $|z - z_0| > R$ — внешность круга
- $|z - z_1| + |z - z_2| = 2a$ — эллипс (см. [[Линии второго порядка]])

## Аргумент
Аргумент — угол между вектором $z$ и положительным направлением $Ox$. Определён неоднозначно, с точностью до $2\pi k$:
$$\operatorname{Arg}z = \arg z + 2\pi k,\ k \in \mathbb Z, \qquad \arg z \in (-\pi; \pi] \text{ — главное значение}$$
У нуля модуль равен 0, а аргумент не определён.

$$\arg z = \begin{cases}
\operatorname{arctg}\frac yx, & x > 0 \\
\operatorname{arctg}\frac yx + \pi, & x < 0,\ y \ge 0 \\
\operatorname{arctg}\frac yx - \pi, & x < 0,\ y < 0 \\
\frac\pi2, & x = 0,\ y > 0 \\
-\frac\pi2, & x = 0,\ y < 0
\end{cases}$$

> [!warning] Четверть
> $\operatorname{arctg}$ сам по себе даёт угол только в I или IV четверти, поэтому четверть определяй по знакам $x$ и $y$.
> Пример: $z = 3 - i\sqrt3$, $\arg z = -\frac\pi6$ (или $\frac{11\pi}{6}$).

## Тригонометрическая и показательная формы
$x = |z|\cos\varphi$, $y = |z|\sin\varphi$:
$$z = |z|(\cos\varphi + i\sin\varphi) = |z|e^{i\varphi}, \qquad e^{i\varphi} = \cos\varphi + i\sin\varphi \text{ (формула Эйлера)}$$

| $z$ | Показательная форма |
|---|---|
| $1$ | $e^{i\cdot 0} = e^{i2\pi k}$ |
| $-1$ | $e^{i\pi}$ |
| $i$ | $e^{i\pi/2}$ |
| $-i$ | $e^{-i\pi/2}$ |
| $1 + i$ | $\sqrt2e^{i\pi/4}$ |
| $1 - i$ | $\sqrt2e^{-i\pi/4}$ |
| $-1 + i$ | $\sqrt2e^{i3\pi/4}$ |
| $-1 - i$ | $\sqrt2e^{-i3\pi/4}$ |

**Умножение и деление:** модули перемножаются (делятся), аргументы **складываются (вычитаются)**:
$$z_1z_2 = |z_1||z_2|\big(\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)\big), \qquad \frac{z_1}{z_2} = \frac{|z_1|}{|z_2|}e^{i(\varphi_1 - \varphi_2)}$$

## Степени и корни
**Формула Муавра:**
$$z^n = |z|^n(\cos n\varphi + i\sin n\varphi) = |z|^ne^{in\varphi}$$

Степени $i$ повторяются с периодом 4: $i^{4k} = 1$, $i^{4k+1} = i$, $i^{4k+2} = -1$, $i^{4k+3} = -i$ — смотри на остаток от деления показателя на 4.

**Корень $n$-й степени** имеет ровно $n$ значений:
$$\sqrt[n]{z} = \sqrt[n]{|z|}\left(\cos\frac{\varphi + 2\pi k}{n} + i\sin\frac{\varphi + 2\pi k}{n}\right), \qquad k = 0, 1, \dots, n-1$$
Они лежат в вершинах правильного $n$-угольника, вписанного в окружность радиуса $\sqrt[n]{|z|}$.

![[Корни n-й степени.png|380]]

| Уравнение | Корни |
|---|---|
| $z^3 = 1$ | $1;\ -\frac12 \pm \frac{\sqrt3}{2}i$ |
| $z^3 = 8$ | $2;\ -1 \pm \sqrt3\,i$ |
| $z^2 = -9$ | $\pm 3i$ |
| $z^4 = -1$ | $\pm\frac{\sqrt2}{2} \pm \frac{\sqrt2}{2}i$ |
| $z^3 = -27$ | $-3;\ \frac32 \pm \frac{3\sqrt3}{2}i$ |

## Уравнения
- **Квадратное с $D < 0$:** $\sqrt D = i\sqrt{|D|}$. Пример: $z^2 + 8z + 25 = 0$, $D = -36$, $z = -4 \pm 3i$.
- **Биквадратное:** замена $t = z^2$. $z^4 + 17z^2 + 16 = 0 \Rightarrow t = -1,\ -16 \Rightarrow z = \pm i,\ \pm 4i$.
- **Кубическое:** подобрать корень среди делителей свободного члена, затем разделить многочлен:
  $z^3 - 5z^2 + 9z - 5 = 0$, $z_1 = 1$, $(z - 1)(z^2 - 4z + 5) = 0$, $z_{2,3} = 2 \pm i$.

> [!example] Сложный случай: комплексный дискриминант
> Ищем $\sqrt D = x + yi$: $(x + yi)^2 = x^2 - y^2 + 2xyi = D$
> $$\begin{cases} x^2 - y^2 = \operatorname{Re}D \\ 2xy = \operatorname{Im}D \\ x^2 + y^2 = |D| \end{cases}$$
> $z^2 - 5z + 4 + 10i = 0$: $D = 9 - 40i$, $|D| = 41$, $x = \pm5$, $y = \pm4$, $xy < 0$, поэтому $\sqrt D = \pm(5 - 4i)$, откуда $z_1 = 5 - 2i$, $z_2 = 2i$.

Системы с комплексными коэффициентами решаются [[Определители и правило Крамера|правилом Крамера]]; при счёте помогают $(1+i)^2 = 2i$, $(1-i)^2 = -2i$.

## Типичные ошибки (из домашек)
- $\operatorname{Im}(-2 + 2\sqrt3 i) = 2\sqrt3$, без $i$.
- В модуль подставляются $x$ и $y$ **без** $i$: $|5 - 12i| = \sqrt{25 + 144} = 13$ (подставлять $(-12i)^2$ нельзя).
- $(a + bi)^2 = a^2 + 2abi - b^2$, а не $a^2 + (bi)^2$. Например, $(1 + i)^2 = 2i$, $(2 + 3i)^2 = -5 + 12i$.
- $(3i)^2 = 9i^2 = -9$.
- Равенство комплексных чисел: $\operatorname{Re} = \operatorname{Re}$ и $\operatorname{Im} = \operatorname{Im}$. $(x + 1) + i(y - 2) = 4 - 5i \Rightarrow x = 3,\ y = -3$.
- $(4 - 5i)(4 + 5i) = 16 + 25 = 41$ — это $z\bar z = |z|^2$.
- При умножении в тригонометрической форме складываются **аргументы** $\varphi_1 + \varphi_2$, а не углы внутри каждого числа отдельно.
- $(1 - i)^4 = (\sqrt2)^4e^{-i\pi} = -4$.
