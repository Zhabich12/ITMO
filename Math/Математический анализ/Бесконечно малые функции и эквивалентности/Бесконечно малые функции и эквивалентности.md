# Бесконечно малые функции и эквивалентности
*Продолжение темы [[Предел функции и замечательные пределы]]; для последовательностей те же понятия разобраны в [[Предел последовательности#Бесконечно малые и бесконечно большие|пределе последовательности]].*

## Бесконечно малые функции
$\alpha(x)$ — **бесконечно малая** при $x \to a$, если
$$\forall\varepsilon > 0\ \exists\delta = \delta(\varepsilon):\ 0 < |x - a| < \delta \Rightarrow |\alpha(x)| < \varepsilon$$

**Теоремы:**
1. $\alpha(x)\cdot f(x)$ — б.м., если $f(x)$ ограничена.
2. $\alpha_1(x) + \alpha_2(x) + \dots$ (конечное число слагаемых) — б.м.
3. **О связи с пределом:** $\lim\limits_{x\to a} f(x) = A \iff f(x) = A + \alpha(x)$, где $\alpha$ — б.м.

**Бесконечно большая:** $\lim\limits_{x\to a} f(x) = \infty$, если
$$\forall E > 0\ \exists\delta = \delta(E) > 0:\ \forall x \in X,\ 0 < |x - a| < \delta \Rightarrow |f(x)| > E$$

## Доказательство первого замечательного предела
$$\lim_{x\to0}\frac{\sin x}{x} = 1$$

![[Первый замечательный предел.png|260]]

1. На единичной окружности дуга $AB = x$, а $BD = \sin x$, поэтому $|\sin x| < |x|$ при $x \neq 0$.
2. Сравним площади: $S_{\triangle OAB} < S_{\text{сектора } OAB} < S_{\triangle OAC}$:
$$\frac12\sin x < \frac12x < \frac12\operatorname{tg}x$$
3. Делим на $\frac12\sin x$ (при малых $x > 0$ он положителен):
$$1 < \frac{x}{\sin x} < \frac{1}{\cos x} \;\Rightarrow\; \cos x < \frac{\sin x}{x} < 1$$
4. $\cos x \to 1$, и по теореме о [[Предел последовательности#Теорема о двух милиционерах|двух милиционерах]] $\dfrac{\sin x}{x} \to 1$.

## О-символика
**$O$ большое:** $f(x) = O(g(x))$ при $x \to a$, если $f(x) = S(x)\,g(x)$, где $S(x)$ ограничена в некоторой окрестности $U_a$. Иначе говоря, $\dfrac{f(x)}{g(x)}$ ограничено в $U_a$ ($g(x) \neq 0$).

**$o$ малое:** $f(x) = o(g(x))$, если $\dfrac{f(x)}{g(x)} \to 0$ — $f$ стремится к нулю быстрее $g$.

**Эквивалентность:** $f(x) \sim g(x)$, если $f(x) = g(x) + o(g(x))$, то есть $\dfrac{f(x)}{g(x)} \to 1$. Тогда $g(x)$ называют **главной частью** $f(x)$.

## Таблица эквивалентностей
Все эквивалентности ниже — при $x \to 0$.
| Эквивалентность | С остатком |
|---|---|
| $\sin x \sim x$ | $\sin x = x + o(x)$ |
| $1 - \cos x \sim \dfrac{x^2}{2}$ | $\cos x = 1 - \dfrac{x^2}{2} + o(x^2)$ |
| $\operatorname{tg}x \sim x$ | $\operatorname{tg}x = x + o(x)$ |
| $\arcsin x \sim x$ | $\arcsin x = x + o(x)$ |
| $\operatorname{arctg}x \sim x$ | $\operatorname{arctg}x = x + o(x)$ |
| $a^x - 1 \sim x\ln a$ | $a^x - 1 = x\ln a + o(x)$ |
| $e^x - 1 \sim x$ | $e^x - 1 = x + o(x)$ |
| $\log_a(1 + x) \sim \dfrac{x}{\ln a}$ | $\log_a(1 + x) = x\log_ae + o(x)$ |
| $\ln(1 + x) \sim x$ | $\ln(1 + x) = x + o(x)$ |

Вместо $x$ можно подставить любую бесконечно малую: $\sin(x - 3) \sim x - 3$ при $x \to 3$, $\arcsin^2 3x \sim 9x^2$ при $x \to 0$.

> [!warning] Где можно заменять
> Эквивалентными можно заменять **множители** в произведении и частном. В сумме и разности замена может дать неверный ответ.

## Главная часть
Бесконечно малую $\beta(x)$ сравнивают со стандартной:
- если $a$ конечно — с $C(x - a)^k$;
- если $a = \infty$ — с $C\left(\dfrac1x\right)^k$.

Бесконечно большие $F(x)$, $G(x)$ при $x \to a$: $G(x) \sim C\,(F(x))^k$, где эталон $\left(\dfrac{1}{x - a}\right)^k$ для конечного $a$ и $x^k$ для $a = \infty$.

## Приёмы с практики
- **Разность косинусов** превращаем в произведение и заменяем множители:
$$\frac{\cos4x - \cos2x}{\arcsin^23x} = \frac{-2\sin3x\sin x}{\arcsin^23x} \sim \frac{-2\cdot3x\cdot x}{9x^2} = -\frac23$$
- **Разность экспонент** — выносим общий множитель, чтобы появилось $e^{t} - 1$:
$$\frac{e^{\alpha x} - e^{\beta x}}{\sin\alpha x} = \frac{e^{\beta x}\left(e^{(\alpha - \beta)x} - 1\right)}{\sin\alpha x} \sim \frac{(\alpha - \beta)x}{\alpha x} = \frac{\alpha - \beta}{\alpha}$$
- **Логарифм от «почти единицы»** — пишем как $\ln(1 + t)$:
$$\frac{\ln\cos x}{x^2} = \frac{\ln\big(1 + (\cos x - 1)\big)}{x^2} \sim \frac{\cos x - 1}{x^2} \sim \frac{-x^2/2}{x^2} = -\frac12$$
$$\frac{\ln x - 1}{x - e} = \frac{\ln\frac xe}{x - e} = \frac{\ln\left(1 + \frac{x - e}{e}\right)}{x - e} \to \frac1e$$
- **При $x \to \infty$** роль бесконечно малой играет $\frac1x$: $\left(a^{1/x} - 1\right)x \sim \frac1x\ln a\cdot x = \ln a$.
- **Если $x \to a \neq 0$** — замена $t = x - a$, чтобы свести к $t \to 0$:
  - $\dfrac{\sin2x}{\sin3x}$ при $x \to \pi$: $\sin2x = \sin2t$, $\sin3x = -\sin3t$, ответ $-\dfrac23$;
  - $(1 - x)\operatorname{tg}\dfrac{\pi x}{2}$ при $x \to 1$: $t = 1 - x$, $\operatorname{tg}\left(\frac\pi2 - \frac{\pi t}{2}\right) = \operatorname{ctg}\frac{\pi t}{2} \sim \frac{2}{\pi t}$, ответ $\dfrac2\pi$.
