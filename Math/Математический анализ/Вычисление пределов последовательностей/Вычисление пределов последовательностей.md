# Вычисление пределов последовательностей
*Приёмы с практики и из домашнего задания (Берман 245–257). Решения есть в PDF рядом с заметкой. Теория — в [[Предел последовательности]].*

## Найти формулу $n$-го члена
- $1, 4, 9, \dots \to n^2$
- знак чередуется — множитель $(-1)^{n+1}$ (или $(-1)^n$)
- нечётные числа — $2n - 1$, например $\frac{(-1)^{n+1}}{2n - 1}$

## Неопределённость $\left[\frac\infty\infty\right]$
Делим числитель и знаменатель на $n$ в **старшей** степени.

Для отношения многочленов $\dfrac{P_k(n)}{Q_m(n)}$:
- $k = m$ — предел равен отношению старших коэффициентов;
- $k < m$ — предел $0$;
- $k > m$ — предел $\infty$.

> [!tip] Скобки в степени
> Раскрывай по биному и смотри на старшие степени: в разностях они сокращаются.
> $(n + 1)^4 - (n - 1)^4 = 8n^3 + 8n$, а $(n + 1)^4 + (n - 1)^4 = 2n^4 + 12n^2 + 2$, поэтому предел отношения равен $0$.

## Корни
Выносим $n$ в нужной степени из-под каждого корня:
$$\sqrt{n^3 - 2n^2 + 1} = n^{3/2}\sqrt{1 - \tfrac2n + \tfrac1{n^3}}, \qquad \sqrt[3]{n^4 + 1} = n^{4/3}\sqrt[3]{1 + \tfrac1{n^4}}$$
Затем делим на **наибольшую** степень. Дробные показатели сравнивай, приведя к общему знаменателю: $\frac32 = \frac96 > \frac43 = \frac86$, значит старшая степень — $n^{3/2}$.

## Неопределённость $[\infty - \infty]$ с корнями
Домножаем на **сопряжённое** выражение и пользуемся формулами сокращённого умножения:
$$\sqrt{n + 2} - \sqrt{n - 4} = \frac{(n + 2) - (n - 4)}{\sqrt{n + 2} + \sqrt{n - 4}} = \frac{6}{\sqrt{n + 2} + \sqrt{n - 4}} \to 0$$
Для кубических корней: $a - b = \dfrac{a^3 - b^3}{a^2 + ab + b^2}$.

## Показательные выражения
Делим на самую быстро растущую степень:
$$\frac{2^n + 7^n}{2^n + 7^{n+1}} = \frac{(2/7)^n + 1}{(2/7)^n + 7} \to \frac17, \qquad \left(\tfrac27\right)^n \to 0$$

## Факториалы
Выносим меньший факториал: $(n + 2)! = (n + 2)(n + 1)!$, $(n + 1)! = (n + 1)\cdot n!$.
$$\frac{(n + 2)! + (n + 1)!}{(n + 2)! - (n + 1)!} = \frac{(n + 1)!\,(n + 3)}{(n + 1)!\,(n + 1)} \to 1, \qquad \frac{n!}{(n + 1)! - n!} = \frac{n!}{n!\cdot n} = \frac1n \to 0$$

> [!warning] Типичные ошибки
> - $\dfrac{n}{n + 2} \to 1$, а не $0$: делим на $n$ и получаем $\dfrac{1}{1 + 2/n}$.
> - $\dfrac{\sqrt[3]{n^3 + 2n - 1}}{n + 2} \to 1$: $\ n\cdot1/(n + 2) \to 1$.
> - $0\cdot\infty$ — это неопределённость, а не $0$.
> - $\dfrac{c}{0} = \infty$ и $\dfrac{c}{\infty} = 0$ — не неопределённости.
