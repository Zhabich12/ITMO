# Предел функции и замечательные пределы
*Продолжение [[Предел последовательности]].*

## Определения предела функции
Пусть $X \subset \mathbb R$, $X \neq \varnothing$, $a$ — предельная точка $X$, $f: X \to \mathbb R$.

**По Коши (на языке окрестностей):**
$$A = \lim_{x\to a} f(x) \iff \forall U_A\ \exists\mathring U_a:\ \forall x \in \mathring U_a \cap X\ \Rightarrow f(x) \in U_A$$
$\mathring U_a$ — проколотая окрестность: сама точка $a$ не учитывается.

![[Предел по Коши окрестности.png|300]]

**По Коши ($\varepsilon - \delta$):**
$$A = \lim_{x\to a} f(x) \iff \forall\varepsilon > 0\ \exists\delta = \delta(\varepsilon):\ \forall x \in X,\ 0 < |x - a| < \delta\ \Rightarrow |f(x) - A| < \varepsilon$$

**По Гейне (на языке последовательностей):**
$$A = \lim_{x\to a} f(x) \iff \forall\{x_n\} \subset X,\ x_n \neq a,\ x_n \to a\ \Rightarrow f(x_n) \to A$$

> [!tip] Как доказать, что предела нет
> По Гейне: достаточно найти две последовательности $x_n \to a$ и $x_n' \to a$, для которых $f(x_n)$ и $f(x_n')$ стремятся к разным числам.

Пример: $f(x) = C$ — для любого $a \in \mathbb R$ $\lim_{x\to a} C = C$.

## Свойства и подстановка
$$\lim C = C, \qquad \lim C\,g(x) = C\lim g(x), \qquad \lim g(x)^{\varphi(x)} = \left(\lim g\right)^{\lim\varphi}$$
Если подстановка не даёт неопределённости, предел равен значению: $\frac50 = \infty$, $\frac5\infty = 0$.

## Раскрытие неопределённостей
**$\left[\frac00\right]$ для многочленов** — разложить на множители и сократить $(x - a)$:
$$\lim_{x\to2}\frac{x^2 - 5x + 6}{x^2 - 12x + 20} = \lim_{x\to2}\frac{(x - 2)(x - 3)}{(x - 2)(x - 10)} = \frac{-1}{-8} = \frac18$$

**$\left[\frac00\right]$ с корнями** — домножить на сопряжённое (иногда и числитель, и знаменатель):
$$\frac{\sqrt{x^2 + 1} - 1}{\sqrt{x^2 + 16} - 4} = \frac{x^2\,(\sqrt{x^2 + 16} + 4)}{x^2\,(\sqrt{x^2 + 1} + 1)} \xrightarrow{x\to0} \frac82 = 4$$

**$[\infty - \infty]$ с дробями** — привести к общему знаменателю: $\dfrac1{1 - x} - \dfrac2{1 - x^2}$.

**$[\infty - \infty]$ с корнями** — сопряжённое: $\sqrt{x^2 + 1} - \sqrt{x^2 - 1} \to 0$ при $x \to \infty$.

**$\left[\frac\infty\infty\right]$** — как для [[Вычисление пределов последовательностей|последовательностей]]: делим на старшую степень.

## Первый замечательный предел
$$\lim_{x\to0}\frac{\sin x}{x} = 1 \qquad \left[\tfrac00\right]$$

Следствия и приёмы:
- $\dfrac{\sin 2x}{x}$: либо $\sin2x = 2\sin x\cos x$, либо замена $t = 2x$: $2\cdot\dfrac{\sin t}{t} \to 2$
- $\dfrac{\operatorname{tg}\alpha x}{x} = \dfrac{\sin\alpha x}{\alpha x}\cdot\dfrac{\alpha}{\cos\alpha x} \to \alpha$
- $\dfrac{\sin(\alpha + x) - \sin(\alpha - x)}{x} = \dfrac{2\cos\alpha\sin x}{x} \to 2\cos\alpha$ — формула разности синусов

> [!example] Сложный случай: $\lim\limits_{x\to\pi/4}\dfrac{\cos x - \sin x}{\cos 2x}$
> $\cos2x = \cos^2x - \sin^2x = (\cos x - \sin x)(\cos x + \sin x)$, поэтому
> $$\lim_{x\to\pi/4}\frac{1}{\cos x + \sin x} = \frac{1}{\sqrt2}$$

## Второй замечательный предел
$$\lim_{x\to\infty}\left(1 + \frac1x\right)^x = e, \qquad \lim_{x\to0}(1 + x)^{1/x} = e \qquad [1^\infty]$$

> [!tip] Схема для $[1^\infty]$
> 1. Привести основание к виду $1 + \alpha(x)$, где $\alpha \to 0$.
> 2. Выделить $\left[(1 + \alpha)^{1/\alpha}\right]^{\alpha\cdot\text{показатель}}$.
> 3. Ответ: $e^{\lim(\alpha\cdot\text{показатель})}$.

Примеры:
- $(1 + \operatorname{tg}x)^{\operatorname{ctg}x}$, $x \to 0$: замена $t = \operatorname{tg}x$, $(1 + t)^{1/t} \to e$
- $\left(\dfrac{x + 1}{x - 1}\right)^x = \left(1 + \dfrac{2}{x - 1}\right)^x = \left[\left(1 + \dfrac2{x - 1}\right)^{\frac{x - 1}{2}}\right]^{\frac{2x}{x - 1}} \to e^2$
- $\left(\dfrac{2x}{2x - 3}\right)^{3x} = \left(1 + \dfrac{3}{2x - 3}\right)^{3x} \to e^{9/2}$
