Элементарный исход - один единственно возможный, неделимый исход(w)

Пространство всех элементарных исходов - множество всех элементарных исходов 

Вероятность - числовая характеристика наступления события 

Вероятностное пространство - математическая модель состоящая из 3 частей:
- Множества всех возможных исходов эксперимента 
- Множества всех событий 
- Функции вероятности(P)

Условная вероятность - вероятность события А если В произошло.

P(А|B) = P(B^A) / P(B) где Р(А) > 0

Теорема Байеса
Р(А|В) = Р(АВ):Р(В) = Р(ВА):Р(В) = Р(В|А) * Р(А) : Р(В)
