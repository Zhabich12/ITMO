# Лабораторное оборудование

Если можно избежать использования взрывоопасных веществ, лучше их избегать.

## Спектрофотометр
- Анализирует только **истинные растворы** (без взвесей и коллоидов, см. [[Растворы#Классификация систем по размеру частиц|классификацию растворов]]).
- Рабочий диапазон оптической плотности — 0–1.
- Материал кюветы должен подходить измеряемому образцу.
- Никаких воздушных пузырьков.

## Весы
- Калибровать перед каждым использованием.
- Выравнивать по уровню каждый раз.
- Очищать после каждого использования.
- Закрывать дверцы во время взвешивания.

## Центрифуга
- Уравновешивать пробирки до 4-го знака.
- Не заполнять пробирку до краёв.
- Настраивать скорость разгона и остановки.
- Некоторые образцы лучше оседают при низких температурах.

## Магнитная мешалка
- Использовать термопару, если ставите что-то с нагревом.
- Сначала положить якорь, потом включить перемешивание.
- Использовать только термостойкое стекло.

## Ламинар
- Класс безопасности бокса должен соответствовать объекту работы.
- Каждый раз калибровать.
- Ничего не двигать внутри во время работы.

Все эти приборы — инструменты стадии «Проведение» в [[Этапы эксперимента|этапах эксперимента]].
