### Что нужно?

I. Файл плазмиды в формате genbank(gb) 
II. Энзимы для работы с рестрикцией
III. Последовательность ДНК для модификации плазмиды 


#### Где искать данные?

Данные можно найти в американской базе данных NCBE, есть также заметка с номенклатурой местной [[NCBE номенклатура для Genbank]]


#### Поиск сайтов рестрикции
Сначало загружаем плазмиду

Для поиска липких концов нужно выбрать операции-анализ-поиск сайтов рестрикции.
![[Pasted image 20251019182505.png]]
После нужно открыть ферменты и загрузить, можно выбрать как все рестриктазы, так и конкретные через поиск. После стоит поставить фильтр по кол-ву результатов от 1 до 1 и собственно подтвердить.

![[Pasted image 20251019182704.png]]
После появиться карта сайтов рестрикции, на карте плазмиды также будут отображаться полученные сайты, наведясь можно получить подробные данные, в том числе о липких концах.

#### ПЦР in silico(НЕ РАБОТАЕТ)

##### Ген
Открываем файл FASTA с нужным геном, сбоку в инструментах выбираем ПЦР in silico, далее нужно подобрать праймеры для ПЦР
![[Pasted image 20251019153116.png]]

##### Подбор праймеров

Итоговый праймер в данном случае будет выглядеть так:
**![[Pasted image 20251019154036.png]]**

Для forward primer выделяем около 20 нуклеотидов с начала гена.
![[Pasted image 20251019153215.png]]

После вставляем данный отрезок в forward primer. Снизу сразу пишется температура плавления этого праймера.
![[Pasted image 20251019153316.png]]

После в начало forward primer вписываем сиквенс первого сайта рестрикции. В данном случае это EcoRi, где сайт рестрикции GAATTC.

Теперь нужно построить ЕЩЕ одну доп.последовательность для рестриктазы, чтобы она более устойчиво держалась на последовательности. Это могут быть любые нуклеотиды перед сайтом рестрикции, должно быть 6-9 нуклеотидов, в данном случае берется AAATCG.
При этом можно вставлять больше нуклеотидов для большей температуры плавления, больше Гуанина и Цитозина для также большей температуры плавления

Обратный праймер строится примерно также, берется около 20 нуклеотидов с конца сиквенса, однако обратный праймер должен быть комплементарным обратной цепи и при этом перевернутой, т.е с 3 конца.
![[Pasted image 20251019154730.png]]

Для этого ниже обратного праймера есть функция reverse complement sequence. Далее идет аналогичный порядок действий, однако для Xbal.
