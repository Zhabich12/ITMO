# HW. Растворы и pH
*Теория и приёмы из домашнего задания. Сами решения есть в PDF рядом с заметкой.*

## Нормальная и молярная концентрация
$$C_{\text{экв}} = z \cdot C_M \quad \Rightarrow \quad C_M = \frac{C_{\text{экв}}}{z}$$
где $z = 1/f$ — число эквивалентности ($z(\mathrm{H_2SO_4}) = 2$, $z(\mathrm{HCl}) = 1$). Подробнее: [[Растворы#Фактор эквивалентности|фактор эквивалентности]].

## Приготовление разбавленного раствора из концентрированного
Цепочка расчёта:
1. $n = C \cdot V$ — сколько вещества нужно
2. $m_{\text{в-ва}} = n \cdot M$
3. $m_1 = \dfrac{m_{\text{в-ва}}}{\omega_1}$ — масса концентрированного раствора
4. $V_1 = \dfrac{m_1}{\rho_1}$ — его объём

Если нужно найти ещё и другие концентрации готового раствора:
- $m_{\text{р-ра}} = \rho_2 \cdot V$, $\quad \omega = \dfrac{m_{\text{в-ва}}}{m_{\text{р-ра}}}$
- $m_{\mathrm{H_2O}} = m_{\text{р-ра}} - m_{\text{в-ва}}$ (**в кг!**), $\quad C_m = \dfrac{n}{m_{\mathrm{H_2O}}}$
- $T = \dfrac{m_{\text{в-ва}}}{V\,(\text{мл})}$

## pH сильных электролитов
**Сильные кислоты** диссоциируют полностью:
$$\mathrm{HCl + H_2O \to H_3O^+ + Cl^-} \qquad [\mathrm{H_3O^+}] = C$$

$\mathrm{H_2SO_4}$ диссоциирует по ступеням:
$$\mathrm{H_2SO_4 + H_2O \to H_3O^+ + HSO_4^-}$$
$$\mathrm{HSO_4^- + H_2O \rightleftharpoons H_3O^+ + SO_4^{2-}}$$
В приближении $[\mathrm{H_3O^+}] \approx 2C$.

**Щёлочи:** $[\mathrm{OH^-}] = C$ для $\mathrm{NaOH}$ и $[\mathrm{OH^-}] = 2C$ для $\mathrm{Ba(OH)_2}$. Дальше
$$\mathrm{pOH} = -\lg[\mathrm{OH^-}], \qquad \mathrm{pH} = 14 - \mathrm{pOH}$$

> [!tip] Сложный случай
> Добавление соли сильной кислоты и сильного основания ($\mathrm{NaCl, Na_2SO_4, NaNO_3, BaCl_2}$) **не меняет** pH: такие соли не гидролизуются, $\Delta[\mathrm{H_3O^+}] = 0$.
