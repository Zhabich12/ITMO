# Динамика
*Лекции 05.10 и 12.10.*

## Приёмы для задач на вращение
- Прямая задача: $\omega = \dfrac{d\varphi}{dt}$, $\ \varepsilon = \dfrac{d\omega}{dt}$
- Обратная задача: интегрировать и найти константы из начальных условий:
$$\omega(t) = \int\varepsilon\,dt + \omega_0, \qquad \varphi(t) = \int\omega\,dt + \varphi_0$$
- Если $S = ct^3$: $\ v = 3ct^2$, $\ a_\tau = 6ct$, $\ a_n = \dfrac{v^2}{R}$
- Частоту в об/мин переводят в об/с делением на 60; $v = \omega R = 2\pi\nu R = \pi\nu d$

## Категории сил (фундаментальные взаимодействия)
1. **Электромагнитное** — действует между зарядами
2. **Гравитационное** — действует между массами
3. **Сильное (ядерное)**
4. **Слабое** — превращения частиц (например, распад нейтрона)

Способы описания движения: **силовой** и **энергетический**.

## Сила тяжести
Закон всемирного тяготения:
$$F = G\frac{m_1m_2}{R^2}, \qquad G = 6{,}67 \cdot 10^{-11}\ \frac{\text{Н·м}^2}{\text{кг}^2}$$
У поверхности Земли:
$$F = G\frac{M_{\text{З}}m}{R_{\text{З}}^2} = mg \quad\Rightarrow\quad g = \frac{GM_{\text{З}}}{R_{\text{З}}^2} \approx 9{,}8\ \text{м/с}^2$$

## Сила реакции опоры
$\vec N$ направлена **перпендикулярно поверхности** опоры.

![[Сила реакции опоры.png|250]]

**Вес в лифте, движущемся с ускорением вверх:**

![[Вес в лифте.png|300]]

$$\vec N + m\vec g = m\vec a \;\xrightarrow{\;Oy\;}\; N - mg = ma \;\Rightarrow\; N = m(g + a), \qquad P = N$$

## Сила трения
**Трение покоя** ($v = 0$): тело не движется, поэтому $\sum\vec F = 0$:
$$-F_{\text{тр}} + F = 0 \Rightarrow F_{\text{тр}} = F$$
Сила трения покоя растёт вместе с приложенной силой до максимума $F_{\text{тр.пок.}\max} = \mu N$, дальше тело скользит и $F_{\text{тр}} = \mu N$.

![[Трение покоя.png|450]]

## Сила упругости
**Закон Гука:**
$$\vec F = -k\vec x$$
$x = l_1 - l_0$ (растяжение) или $x = l_2 - l_0$ (сжатие), $k$ — коэффициент жёсткости.

![[Сила упругости.png|300]]

**Сила Архимеда:** $F_A = \rho g V_{\text{погр}}$.

> [!example] Сложный случай: при каком угле тянуть брусок с наименьшей силой?
> ![[Сила под углом.png|350]]
> $Oy$: $F\sin\alpha - mg + N = 0 \Rightarrow N = mg - F\sin\alpha$
> $F_{\text{тр}} = \mu N = \mu(mg - F\sin\alpha)$
> $Ox$: $F\cos\alpha - \mu(mg - F\sin\alpha) = 0$
> $$F(\cos\alpha + \mu\sin\alpha) = \mu mg \quad\Rightarrow\quad F = \frac{\mu mg}{\cos\alpha + \mu\sin\alpha}$$
> $F$ минимальна, когда знаменатель максимален. Приравниваем производную к нулю:
> $$(\cos\alpha + \mu\sin\alpha)' = -\sin\alpha + \mu\cos\alpha = 0 \;\Rightarrow\; \operatorname{tg}\alpha = \mu,\quad \alpha = \operatorname{arctg}\mu$$

## Связанные тела
![[Связанные тела на наклонной.png|400]]

![[Невесомая нить.png|300]]

- Нить **невесома**: $T_1 - T_2 = ma = 0$ (при $m = 0$), значит $T_1 = T_2 = T$
- Нить **нерастяжима**: $a_1 = a_2 = a$

Уравнения записывают для **каждого тела отдельно**:
- 1 тело (висит): $\vec T + m\vec g = m\vec a$, на ось: $mg - T = ma$
- 2 тело (на наклонной, $\alpha = 30°$): $\vec T + \vec N + m\vec g + \vec F_{\text{тр}} = m\vec a$, где
$$N = mg\cos\alpha, \quad F_{\text{тр}} = \mu N, \quad T - mg\sin\alpha - F_{\text{тр}} = ma$$

## Второй закон Ньютона в общем виде
$$\boxed{\vec F = \frac{d\vec p}{dt}} \qquad \vec F\,\Delta t = \Delta\vec p$$

> [!example] Сложный случай: брусок на доске
> ![[Брусок на доске.png|350]]
> По третьему закону Ньютона силы трения между телами равны: $F_{\text{тр1}} = F_{\text{тр2}} = F_{\text{тр}}$. Вес бруска $\vec P$ давит на доску.
>
> **1 тело (брусок):** $\vec N + \vec F_{\text{тр1}} + m\vec g = m\vec a$
> $Ox$: $F_{\text{тр}} = ma$; $\ Oy$: $N - mg = 0$, откуда $a = \mu g$
>
> **2 тело (доска):** $\vec F + \vec P + M\vec g + \vec N_2 + \vec F_{\text{тр2}} = M\vec a$
> $Ox$: $F - F_{\text{тр}} = Ma$; $\ Oy$: $N_2 - P - Mg = 0$
>
> Кинематика, которая здесь пригодилась:
> $$L = \frac{v^2 - v_0^2}{2a} = v_0t + \frac{at^2}{2} = \frac{v_0 + v}{2}\,t$$

## Сила сопротивления, зависящая от скорости
> [!example] Сложный случай: $F = -kv^2$, найти время, за которое скорость упадёт вдвое
> $$F_c = ma \;\Rightarrow\; -kv^2 = m\frac{dv}{dt}$$
> **Разделяем переменные** и интегрируем:
> $$-\frac km\int_0^t dt = \int_{v_0}^{v_0/2}\frac{dv}{v^2}$$
> $$-\frac km\,t = -\frac1v\Big|_{v_0}^{v_0/2} = -\left(\frac{2}{v_0} - \frac{1}{v_0}\right) \;\Rightarrow\; t = \frac{m}{v_0k}$$

## Динамика вращательного движения
Аналогия с поступательным движением:

| Поступательное | Вращательное |

| $S$ | $\varphi$ |
| $v$ | $\omega$ |
| $a$ | $\varepsilon$ |
| $x_0,\ v_0$ | $\varphi_0,\ \omega_0$ |
| $\vec F = m\vec a$ | $\vec M = I\vec\varepsilon$ |
| $\vec p = m\vec v$ | |
| $\vec F\,\Delta t = \Delta\vec p$ | |

## Моменты инерции ($I$)
**1. Материальная точка:** $I = mR^2$

**Система материальных точек:**
$$I = \sum_{i=1}^{n} m_iR_i^2$$

**Твёрдое тело** (сумма по бесконечно малым массам $dm$):
$$I = \sum R^2\,dm = \int_V R^2\,dm$$

## Блок с грузом
![[Блок с грузом.png|150]]

- **1 тело (груз):** $\vec T + m\vec g = m\vec a$, отсюда $mg - T = ma$
- **2 тело (блок):** $\sum\vec M = I\vec\varepsilon$, где момент силы натяжения $M_T = T\cdot R$, поэтому $T R = I\varepsilon$
- Связь: $a = \varepsilon R$ (нить не проскальзывает)
